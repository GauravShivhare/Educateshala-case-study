# EducateShala Features

EducateShala is being built as a school management SaaS that helps schools handle their daily operations in a more organized way.

## Core Product Direction

The product focuses on role-based school workflows. Each user should see only the data and tools that are relevant to their role and school.

## Current / In-Progress Features

### Authentication

- UID/password login direction
- OTP forgot password flow
- Role-based access after login
- Profile management

### Super Admin

- View high-level school overview
- Manage schools
- View school status
- Access school-level details
- Future broadcast notification system

### School Management

- Add and manage school records
- Maintain school-specific data separation
- Support active and blocked school states

### User Management

- Manage users by role
- Role separation for Super Admin, School Admin, Principal, Office Staff, Teacher, Student, and Parent
- School-level user visibility

### Teacher Workflow

- Teacher class-section assignment
- Teachers can work only with assigned class/section students
- Student management workflow

## AI Assistant MVP Features

### AI School Admin Assistant

An assistant that helps school staff complete routine administrative work faster.

### AI Notice Generator

Generate school notices, announcements, and messages in a clear format.

### AI Student Performance Summary

Summarize student records and performance indicators for teachers and school staff.

### AI Report Generator

Generate school-level and student-level reports.

### AI Support Chatbot

Help school staff understand how to use the platform and complete common tasks.

### AI History And Actions

- Save recent generated outputs
- Copy output
- Download `.txt`
- Use notice output as a notification draft after manual review

## Product Safety Direction

- Keep production source code private
- Never expose credentials
- Never expose environment files
- Preserve role-based access control
- Preserve school-level data separation
- Keep Template AI Mode clearly labelled during the hackathon demo
