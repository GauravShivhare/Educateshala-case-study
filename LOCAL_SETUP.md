# EducateShala Local Setup

This repository is a public case-study/proof-of-work repository. The private production source code is not included.

## Local App Type

EducateShala is a Core PHP + MySQL school management SaaS MVP that runs locally on XAMPP.

## Local Environment

- PHP through Apache/XAMPP
- MySQL through phpMyAdmin
- HTML, CSS, JavaScript frontend
- JWT-style authentication direction
- Role-based access control direction
- School-scoped data model direction
- Template AI Mode for hackathon demo reliability

## Local Run Flow

```text
Browser → Apache/XAMPP → PHP APIs → MySQL → JSON response → Dashboard UI
```

## AI Assistant Mode

The Day 4 hackathon demo uses Template AI Mode by default. This means the demo does not require external AI API keys and remains stable during presentation.

Live AI provider support can be added later after production hardening.
