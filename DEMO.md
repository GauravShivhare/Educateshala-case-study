# EducateShala Demo Guide

## Demo Goal

Show EducateShala as a working hackathon MVP for a school management SaaS with an AI School Admin Assistant.

## Demo Format

The project can be demonstrated through:

1. Pitch deck
2. Product screenshots
3. Recorded walkthrough video
4. Local screen-share demo if requested

## Recommended Demo Flow

```text
1. Open the dashboard
2. Show role-based sidebar
3. Open AI Assistant
4. Show Template AI Mode badge
5. Generate a school notice
6. Generate a student summary
7. Generate a class report
8. Ask the Admin Help Chatbot a school workflow question
9. Show history section
10. Show copy/download actions
11. Explain that generated notice can be used as a notification draft
```

## Demo Script Summary

EducateShala is a school management SaaS MVP built for schools, admins, teachers, students, and parents.

For the hackathon, the focus was to make the app demo-ready and ship the AI School Admin Assistant module.

The assistant helps school staff generate notices, student summaries, class reports, and admin workflow guidance from one dashboard.

The current MVP uses Template AI Mode for reliable demo output without external API keys. Live AI provider support can be added later.
