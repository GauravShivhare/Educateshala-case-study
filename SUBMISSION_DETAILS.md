# EducateShala Hackathon Submission Details

## Project Name

EducateShala

## Project Type

School Management SaaS MVP with AI School Admin Assistant

## What Was Built

EducateShala is a school management SaaS MVP for schools, admins, principals, office staff, teachers, students, and parents.

The product direction includes school workflows such as:

- Role-based dashboards
- School and user management
- Classes and sections
- Student records
- Attendance direction
- Homework direction
- Fees direction
- Exams and marks/results direction
- Notifications
- Chat / communication direction
- AI-assisted school admin work

For the hackathon, the main focus was to prepare a working MVP direction and ship the AI School Admin Assistant module inside EducateShala.

## AI School Admin Assistant

The AI Assistant helps school staff:

- Generate school notices
- Create student performance summaries
- Prepare class reports
- Answer school admin workflow questions
- Save generated outputs in history
- Copy/download outputs
- Use generated notices as notification drafts

## Current MVP Mode

The current hackathon demo uses Template AI Mode.

This is intentional because it keeps the demo reliable without external API keys or provider failures.

Live AI provider support can be added later after production hardening.

## Why Source Code Is Not Public

The full source code is not public because EducateShala is an active SaaS/startup project.

The private codebase may contain sensitive implementation details, authentication logic, database structure, business logic, and environment-specific configuration.

This public repository is used for case-study, proof-of-work, pitch, screenshots, roadmap, and hackathon documentation.
