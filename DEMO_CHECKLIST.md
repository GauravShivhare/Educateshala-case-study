# Fixeducation Demo Checklist

This file lists the proof-of-work items that can be added before submitting hackathon applications.

## Current Status

- Public live demo: Not available yet
- Public source code: Private, because this is an active SaaS product
- Public proof-of-work: Case study, roadmap, architecture, and hackathon plan

## Screenshots to Add

Add screenshots only after hiding private data, credentials, passwords, OTPs, database details, and admin information.

Recommended screenshots:

1. Login / authentication screen
2. Forgot password / OTP flow screen
3. Super Admin dashboard screen
4. School management workflow screen
5. User management workflow screen
6. Teacher class-section assignment screen
7. Student management workflow screen
8. Role-based dashboard example

## Demo Video Plan

A short 60-90 second screen recording can explain:

1. What Fixeducation is
2. Which problem it solves for schools
3. Current screens or local development progress
4. Planned AI School Admin Assistant
5. How Codex will be used during the hackathon

## What Not to Upload

Do not upload:

- .env files
- Passwords
- OTP values
- SMTP credentials
- Database credentials
- Admin login credentials
- Private school/user data
- Full production source code

## Application Proof Stack

Use these items in hackathon applications:

- LinkedIn profile
- GitHub case study repository
- Product roadmap
- Architecture overview
- Demo screenshots, if available
- Demo video, if available
