## What Not to Upload

Do not upload:

- `.env` files
- Passwords
- OTP values
- SMTP credentials
- Database credentials
- Admin login credentials
- JWT tokens
- API keys
- Private school/user data
- Full production source code
- Database dumps
- Dependency folders
- Raw MP4 video files
